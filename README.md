## Χαρακτηριστικά
- **Live 60s Download/Upload Sparkline** + στατιστικά συνεδρίας.
- **Native Win32 `iphlpapi` TCP/UDP Inspector:** Δείχνει ποια διεργασία (Process/PID) συνδέεται σε ποια IP/Port χωρίς αργά `netstat` spawns.
- **Προσαρμογείς & Κωδικοί Wi-Fi:** IPv4, Gateway, DNS, ταχύτητα Mbps + 1-κλικ προβολή και αντιγραφή αποθηκευμένων κωδικών Wi-Fi.
- **Ping & 1-Κλικ DNS:** Ταυτόχρονο Ping σε `1.1.1.1`, `8.8.8.8`, custom host, `Flush DNS`, και 1-κλικ εναλλαγή Cloudflare / Google / DHCP DNS.
- **Ultra-Light:** `~75 KB` EXE, 0 DLLs, 0 MB idle RAM, Dark/Light Monokai θέμα & παράθυρο **`i`**.
